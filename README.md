# 🏛️ Atrativos Turísticos - Vaticano

> Um projeto web responsivo e estilizado para apresentar os principais pontos turísticos do Vaticano, combinando imagens, vídeos e textos informativos sobre a história e arte da região.

---

## 📌 Sobre o Projeto

Este projeto consiste em uma página web sobre o turismo no Vaticano, desenvolvida com HTML5 e CSS3. A página foi pensada para apresentar de forma clara, bonita e atrativa as informações sobre a **Capela Sistina**, os **Museus do Vaticano** e a **Basílica de São Pedro**.

---

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido com as seguintes tecnologias:

* **HTML5:** Estruturação semântica da página (`<header>`, `<main>`, `<section>`, `<figure>`, `<footer>`, etc.).
* **CSS3:** Estilização com Flexbox para layout responsivo e dinâmico, além de fontes customizadas via Google Fonts (*Tangerine*).
* **Reset CSS:** Normalização de estilos padrão entre navegadores.

---

## 🎨 Destaques do Estilo

* **Layout Flexbox:** Utilizado nas seções de introdução e exibições alternadas de imagens e textos.
* **Tipografia Personalizada:** Uso da fonte *Tangerine* para títulos principais e rodapé.
* **Mídia Adaptável:** Otimização da exibição de vídeo e imagens utilizando `object-fit: cover` e bordas personalizadas.
